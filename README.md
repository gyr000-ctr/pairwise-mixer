# pairwise-mixer

## 题面（可直接粘贴）

给多轨音频混音加增益、限幅与流式处理。约束：单轨原样输出；多轨逐样本求和；限幅要带 attack/release 且不产生削波失真；轨道长度不一致时短轨补零；非法增益与非有限样本要给出可区分的错误；48kHz 一小时的流式混音峰值内存不超过 8 MB；混音耗时随样本数线性且批量 100 万样本不超过 1 秒；并发混音同一对象结果与串行一致；单轨旧路径逐样本不变。验收：python -m pytest tests -q -k mix。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分，不在可见测试里）

- 并发混音
- 1 小时长轨内存上界
- 非有限样本
- 增益为负
- 极限限幅不产生失真

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线），通过不代表满分。
